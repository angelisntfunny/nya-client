# Nya Client
Nya Client is an open-source alternative to clients like Lunar and Feather.

## Building

First, install IntelliJ IDEA.<br>

Then, open up the folder for the version you want to build for (currently only 1.8.9) in IDEA. It should ask you for a JDK, to which you should set Java 21.<br>

After that, follow [this guide](https://docs.fabricmc.net/develop/getting-started/intellij-idea/building-a-mod) from Fabric.

## Using

There will be a launcher made soon, but in the meantime you can install Legacy Fabric in Prism Launcher and add this mod and the Legacy Fabric API.
